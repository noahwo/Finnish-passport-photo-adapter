# Finnish Passport Photo Adapter

Straighten, scale, and crop a portrait to meet Finnish passport photo requirement in [Poliisin passikuvaohje](https://poliisi.fi/documents/25235045/31329600/Poliisin-passikuvaohje-2020-FI.pdf/d7709348-8248-09a0-8b74-7526e6ee2a5d?t=1600339651285).

## Requirements

The app only needs a modern web browser.


## Quick Start

Open `passportgen.html` in a browser.

## How It Works

Use **Open Photo**, then click:

1. one eye
2. the other eye
3. the top of the head
4. the bottom of the chin

The app straightens, scales, crops, and downloads a 500 x 653 pixel passport
photo.
